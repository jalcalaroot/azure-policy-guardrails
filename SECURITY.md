# Security Policy

These are personal learning examples of Azure Policy, not a supported product. There are no version branches: only `main` is maintained.

## Reporting a vulnerability

If you find a security issue (a leaked credential in the history, a definition that weakens a guardrail), please report it privately through GitHub's *Report a vulnerability* feature in the Security tab, not in a public issue.

## Scope

In scope: the Terraform configuration and the policy assignments it defines. Out of scope: Azure Policy itself and Microsoft's built-in definitions.
